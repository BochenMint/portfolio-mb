# PORTFOLIO MB — agent notes

## Design skills (ładuj przy UI)

Projektowe skille leżą w `.cursor/skills/` (nie w `~/.cursor/skills-cursor/`). Przy pracy nad wyglądem landingów **przeczytaj SKILL.md** z tej listy:

| Skill | Kiedy |
| --- | --- |
| `.cursor/skills/frontend-design/SKILL.md` | Nowa lub przebudowywana powierzchnia UI (studio, mb-ai, chrome) |
| `.cursor/skills/landing-critique/SKILL.md` | Recenzja / szlif hero, szkła, kontrastu, nava, StyleSelector |
| `.cursor/skills/editorial-type/SKILL.md` | Fonty, skala, rytm, spacing |
| `.cursor/skills/studio-motion/SKILL.md` | Kursor, `--spot-*`, keyframes, `prefers-reduced-motion` |

Poza zakresem tych skilli (chyba że user wyraźnie każe inaczej): `src/v4/**` (gra / hangar) oraz treść oferty.

Odpowiedzi do usera: polski.
